# 示例对话（session-1）

下面是一轮典型交互，展示"用户只给两样 / agent 按结构输出"的形态。

## 用户输入

```
我目前有：
- 一套写了三年的系统方法论文档（约 1 万段，Word）
- 一个微信私域约 800 人，多是同行从业者
- 每周能挤出 10 小时

我面临：
- 一个月内需要赚到 10 万现金，用于下一步工作
- 没有成品、没有公开作品、没人知道我这套东西
- 行业里已有几个知名付费社群，势头很猛
```

## Agent 输出（节选）

```
【态势判断】
- 优势：成体系的方法论（稀缺资产）、精准私域（800 同行，高质量）、有稳定时间投入。
- 劣势：无成品、无公开信誉、势能为零；与头部社群正面竞争会吃亏。
- 外部机会：行业热度上行，同行有"被带飞"需求；可把文档蒸馏成小产品。
- 外部威胁：头部社群已占认知，抢公开流量会被压制。

【敌友划分】
- 友军：私域里认可你的 800 人、愿意尝鲜的同行。
- 阻力：头部付费社群（占认知、抢公开流量）。
- 可争取者：私域里观望、但能被"可见进展"转化的同行。

【下一步规划】
1. 动作：把文档蒸馏成 3 个可卖小产品（诊断表 / 速查卡 / 1v1 诊断）
   谁来做：你　何时：第 1–2 天　验收：产出可预览的成品页
2. 动作：私域内做一场免费公开诊断，用真实案例造"可见进展"
   谁来做：你　何时：第 3–4 天　验收：≥30 人参与、产出案例
3. 动作：对私域意向者开预售（收意向金），不公开硬刚头部
   谁来做：你　何时：第 5–7 天　验收：预售到账 ≥ 3 万

【准备清单】文档提炼模板、预售收款码、案例记录表。

【已知 / 未知 / 假设】
- 已知：有文档、有私域、有时间。
- 未知：私域真实付费意愿（需预售验证）。
- 假设：800 人里约 5%–10% 可能转化（待预售数据校正）。

【复盘】（执行后填）
```

> 注：示例为说明形态，具体数字属"假设"，需用真实预售数据校正。
